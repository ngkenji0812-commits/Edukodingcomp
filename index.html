Origin Story

Perjuanganku tidak menghapus impianku. Justru membuatnya lebih kuat.

Saat aku kelas 3 SD, ayahku meninggal. Itu adalah salah satu bagian tersulit dalam hidupku. Tetapi dari pengalaman itu, aku belajar bahwa masa depan tidak datang sendiri. Masa depan harus dibuat pelan-pelan, satu langkah demi satu langkah.

Itulah alasan aku ingin menjadi developer. Coding mengajariku bahwa error bukan akhir. Error adalah tanda bahwa aku harus berpikir lebih teliti, mencoba lagi, dan menemukan solusi.

My struggle does not erase my dream. It makes it stronger.

When I was in grade 3, my dad passed away. It was one of the hardest parts of my life. From that experience, I learned that the future does not appear by itself. The future must be built slowly, step by step.

That is why I want to become a developer. Coding teaches me that errors are not the end. Errors are signs that I need to think carefully, try again, and find a solution.

Future Project Blueprint

EduQuest: game impian yang seru dulu, edukatif juga.

EduQuest adalah ide game Roblox masa depanku. Pemain masuk ke dunia petualangan, menyelesaikan quest, melawan tantangan, dan membuka area baru. Bedanya, setiap quest menyelipkan bahasa Inggris, matematika, logika, dan kerja sama.

EduQuest: fun first, educational too.

EduQuest is my future Roblox game idea. Players enter an adventure world, finish quests, face challenges, and unlock new areas. The difference is that every quest includes English, math, logic, and teamwork.

Developer Values

My principles as a developer

Fun

Game harus menyenangkan dulu agar pemain mau belajar.

The game must be fun first so players want to learn.

Fair

Level harus menantang, tapi tidak membuat pemain menyerah.

Levels should be challenging, but not make players give up.

Safe

Game harus ramah untuk anak-anak dan membawa energi positif.

Useful

Game bisa menghibur sekaligus membantu pemain berkembang.

A game can entertain while helping players grow.
